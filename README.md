# Smart City Data Analysis Project

## Overview
This project analyzes Smart City datasets, focusing on Delhi traffic-related data, to uncover meaningful patterns and insights that support data-driven urban planning decisions.

## Objective
To clean, process, and visualize real-world city data in order to identify key traffic trends and patterns.

## Tools & Technologies
- **Language:** Python
- **Libraries:** Pandas, NumPy, Matplotlib
- **Visualization:** Power BI
- **Environment:** Google Colab / Jupyter Notebook

## What I Did
- Cleaned and preprocessed raw traffic data, handling missing values and inconsistencies
- Analyzed key traffic-related features to identify patterns
- Built visualizations to present findings clearly
- Collaborated with a 5-member team as part of Samsung Innovation Campus (SIC) Big Data training
